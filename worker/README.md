# Ретранслятор Paper Wings

Маленький сервер, через который два игрока видят ходы друг друга. Игру он не знает: для
него пакет — непрозрачный конверт, который надо передать второму и, в двух случаях,
придержать.

## Зачем он вообще нужен

Даже «прямое» соединение между двумя браузерами (WebRTC) начинается с того, что кто-то
третий сводит их вместе: браузеры не умеют находить друг друга в интернете сами. Раз
посредник неизбежен, проще сделать его же и почтальоном — тем более что игра пошаговая и
переслать надо один пакет на ход, а не поток кадров.

## Сколько это стоит

Бесплатно, с большим запасом. На free-плане Cloudflare даёт 100 000 запросов в сутки и
313 000 ГБ·с длительности. Пошаговая партия — это десятки пакетов, а между ходами комната
**спит**: режим hibernation сохраняет соединения, выгружая объект из памяти, и время сна
не тарифицируется. Именно ради этого в коде `acceptWebSocket`, а не `accept`.

Одно условие: на free-плане Durable Objects бывают только на SQLite, поэтому в
`wrangler.toml` стоит `new_sqlite_classes`, а не `new_classes`. С `new_classes` деплой
откажет с ошибкой 10097.

## Развернуть

```sh
cd worker
npx wrangler deploy
```

Wrangler попросит войти в аккаунт Cloudflare и выдаст адрес вида
`https://paper-wings-relay.<аккаунт>.workers.dev`.

Дальше впиши его в `script.js`, в `ONLINE_RELAY_URL`, заменив `https://` на `wss://`:

```js
const ONLINE_RELAY_URL = "wss://paper-wings-relay.<аккаунт>.workers.dev";
```

Проверить, не трогая код, можно и через ссылку: `?relay=wss://...` перебивает эту
настройку.

## Ссылки для игры

Создатель комнаты — синий; его настройки становятся правилами партии.

```
https://<сайт>/?room=barsuk&seat=blue     — себе
https://<сайт>/?room=barsuk&seat=green    — другу
```

Имя комнаты — любое, лишь бы у двоих совпало. В телеграм-версии его отдаст `start_param`
мини-приложения.

Без `?relay=` и без заполненного `ONLINE_RELAY_URL` игра работает через `BroadcastChannel`,
то есть между двумя вкладками одного браузера. Это не заглушка, а рабочий режим: на нём
удобно проверять всё остальное, не поднимая сервер.

## Что комната помнит

Ровно два последних пакета, и оба — чтобы вернувшийся после обрыва мог продолжить:

* `settings` — настройки создателя комнаты;
* `state` — последний снимок партии.

Оба лежат в хранилище объекта, а не в памяти: сон память не переживает.

## Проверка без Cloudflare

Вся логика комнаты — в `room.js`, без единой строчки про WebSocket и Durable Object.
Поэтому её крутит и локальный сервер на `ws`, и проверяет `scripts/smoke-online-relay.js`.
Облако из тестов не поднять, а эту логику — можно.
